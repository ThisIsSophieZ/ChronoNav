# ⏱️ ChronoNav

**简体中文** · [English](./README.en.md)

**为 Gemini 注入真实时间锚点，让冗长对话重获掌控。**

ChronoNav 是一款专为 Gemini 网页版设计的轻量级 Chrome 扩展。它能够在前端无感知的状态下，为你发出的每一条 Prompt 静默注入本地系统时间；同时在页面右侧生成一个具备呼吸感、全局可交互的对话时间线（Timeline TOC）。

ChronoNav 是独立扩展，与 Google 或 Gemini 没有关联，未获得其认可、背书或赞助。

如果你经常在 Gemini 中进行跨时段的 DevOps 运维排查、长线程的代码调试，或者常常在数百屏的深度对话中迷失上下文，这个扩展就是为你量身定制的。

## 💡 为什么开发它？

大模型虽然聪明，但往往缺乏真实的“时间感知”。

这会导致在长线任务中出现微妙的脱节：你无法让它准确理解“半小时前的报错”、“昨晚的计划”与“现在的状态”之间的时序关联。此外，在长达几十轮的深水区对话中，传统的滚动查找早已无法满足快速定位关键上下文的需求。

ChronoNav 完美解决了这两个痛点：**底层补全时间上下文，表层重塑长对话导航。**

## ✨ 核心特性

- **⏳ 隐式时间锚点 (System Time Injection)**
  - 扩展会在你发送消息的瞬间，在 Request Payload 中静默追加精确到秒、**带时区标识**的本地时间戳（如 `[System Time: 2026-06-18 21:34:12 +08:00 (Asia/Shanghai)]`），让模型跨时区也能准确换算。
  - UI 气泡保持纯净，而大模型则获得了清晰的时间线索，有效提升日志排查和日程推理的准确度。
- **🗺️ 动态全局大纲 (Interactive Timeline TOC)**
  - 右侧自动生成带彩色节点的“地铁图”式时间线。点击任意节点即可平滑滚动（Smooth Scroll）至对应的历史消息。
  - 支持活动项追踪（Active Item Tracking），当主页面滚动时，侧边栏会自动高亮并居中当前处于视口内的对话节点。
- **🖱️ 单步极速导航 (Step-by-Step Navigation)**
  - 侧边栏两端配备极简的上下导航箭头，支持在相邻的上下文模块间进行幻灯片式的单步跳转，免去滚轮的视觉疲劳。
- **🎨 克制与呼吸感 UI (Glassmorphism & Idle State)**
  - 完美适配 Gemini 的深浅色原生主题。
  - 引入闲置状态（Idle State）：鼠标离开后自动收拢为最右侧的极简彩色点阵，绝不打扰你的屏幕视野；悬停时丝滑展开大纲，并精准浮现当时的发送时间。
- **⌨️ A11y 无障碍语义**
  - 侧边栏标注为导航地标（`role="navigation"`），条目与箭头均带有可读名称（`aria-label`）。
  - 支持键盘聚焦：当焦点进入侧边栏时，闲置态会自动展开，方便键盘用户操作。

## 🛡️ 数据安全 (Zero Tracking)

作为一款辅助工具，安全与合规是第一准则：

- **开发者不收集数据**：无分析、无追踪、无广告，也不会向开发者发送任何数据。
- **请求极简**：时间戳、UTC 偏移量和浏览器时区仅随你原本就要发往 `gemini.google.com` 的请求一同发送，不与任何第三方服务器通信。
- **无敏感权限**：仅在 `gemini.google.com` 注入内容脚本读取页面 DOM，不申请 `tabs`、`cookies` 或同步 `storage` 等敏感权限。

## 🚀 安装与使用

目前本项目通过开发者模式运行：

1. 克隆或下载本仓库源码。
2. 在 Chrome 中打开 `chrome://extensions/`。
3. 开启右上角的「开发者模式」。
4. 点击「加载已解压的扩展程序」，选择包含 `manifest.json` 的项目根目录。
5. 刷新 [Gemini 网页端](https://gemini.google.com/)，即可在右侧看到呼吸状态的时间线大纲。

## 📁 架构与开发

本项目保持极简架构，无构建工具依赖（Zero Build Step）：

- `manifest.json`：MV3 基础配置。
- `content.js`：DOM 解析、大纲生成、滚动监听与 UI 状态机。
- `inject.js`：XHR/Fetch 拦截，负责静默时间注入。
- `sidebar.css`：毛玻璃特效、贝塞尔动画与闲置态响应式布局。
- `icons/`：扩展图标资源（16 / 32 / 48 / 128）。
- `_locales/`：界面与商店描述的多语言文案（en / zh_CN，基于 `chrome.i18n`）。

欢迎提交 PR 或 Issue。修改源码后，直接在扩展页面点击“重新加载”并刷新 Gemini 即可生效。
