# Store Assets Guide / 商店图形资产拍摄指引

Chrome Web Store 上架需要图形资产。本文件列出尺寸规格、建议张数与每张内容。
截图必须展示真实产品，需你在真实 Gemini 页面截取；本指引帮你拍得规范、好看。

---

## 1. 资产规格一览

- **商店图标 / Store icon**：128 x 128 PNG。已就绪：`icons/icon128.png`（已确认为 128x128）。
- **截图 / Screenshots**：
  - 尺寸：**1280 x 800**（推荐）或 640 x 400，PNG 或 JPEG。
  - 数量：至少 1 张，最多 5 张。建议 **3 到 5 张**。
  - 要求：必须是产品真实界面，不能误导；建议同一尺寸保持一致。
- **小促销图块 / Small promo tile**（可选）：440 x 280 PNG/JPEG。
- **Marquee 大促销图**（可选）：1400 x 560 PNG/JPEG。

> 截图统一用 1280x800：若浏览器窗口非该尺寸，可截图后用图像工具裁切/缩放到 1280x800，
> 或加纯色/品牌色背景画布把界面居中。

---

## 2. 建议的 5 张截图内容

按“功能价值”排序，第一张最重要（商店列表里最先展示）：

1. **核心价值：时间线大纲总览**
   - 一段较长的 Gemini 对话，右侧显示完整的彩色节点时间线。
   - 让“地铁图式大纲 + 多条消息”的整体观感一眼可见。

2. **悬停浮现时间**
   - 鼠标悬停某个大纲条目，时间（如 `21:34`）浮现。
   - 体现“时间按需出现、界面不冗余”。

3. **时间锚点真实生效**
   - 让 Gemini 复述它收到的系统时间（用不含 `[ ]` 的提问，避免歧义），
     回答中出现 `[System Time: ...]`；同时页面气泡里看不到该前缀。
   - 证明“底层补全时间上下文、表层纯净”。

4. **深色主题适配**
   - 切到 Gemini 深色主题，展示侧栏毛玻璃自动跟随深色。
   - 与第 1 张浅色形成对比。

5. **闲置点阵态 / 上下导航**
   - 展示鼠标移开后收拢的极简点阵态，或顶部/底部上下箭头导航。
   - 体现“克制、不打扰”。

> 如只放 3 张：建议选 1、2、4（总览 + 悬停时间 + 深色）。

---

## 3. 拍摄小贴士

- 用一段“看起来真实、有内容”的对话，避免空白或敏感信息。
- 截图前清理浏览器书签栏/无关弹窗，画面更干净。
- 浅色与深色各来一张，覆盖两种主题。
- 时间线条目足够多（建议 6 条以上），更能体现“长对话导航”的卖点。
- 文件命名建议：`screenshot-1-overview.png`、`screenshot-2-hover-time.png` 等，便于上传排序。

---

## 4. 促销图（可选，提升曝光）

- 小促销图 440x280：左侧放 128 图标或品牌名，右侧一句卖点（如
  “Give Gemini a sense of time”）。
- Marquee 1400x560：横幅式，适合被编辑推荐时展示。
- 这两类是营销图，可不使用真实截图；如需我用图像生成工具来做，告诉我即可。

---

## 5. 资产存放建议

- 建议在仓库新建 `store-assets/`（或本地目录）存放截图与促销图，不要打进扩展 ZIP。
- 扩展 ZIP 由 `scripts/package.ps1` 生成，只含运行文件，不含任何图形资产或文档。
